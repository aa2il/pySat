On RPi:

Easy way - Use s/w manager to install qsstv - it came right up out of the box!

Hardway:
sudo apt-get install g++ libfftw3-dev qt5-default libpulse-dev
sudo apt-get install libhamlib-dev libasound2-dev libv4l-dev
sudo apt-get install libopenjp2-7 libopenjp2-7-dev

Unpack qsstv tar ball:
tar -xvzf qsstv_9.4.4.tar.gz
cd to source dir
qmake
sudo make install
